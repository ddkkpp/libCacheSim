# 标签噪声偏好 trace

目的：在保持工作负载偏好稳定的同时，引入干扰对象污染对象级未来距离标签。

- 稳定有效规则：候选对象在短间隙扫描后必定返回。
- 噪声规则：毒药对象在返回后注入，且大小偏置（候选=4,096B，毒药=262,144B）。
- 预期困难目标（LRB/3LCache）：字节导向反馈被大量大对象的无返回样本主导，与稳定短复用规则冲突。
- 预期容易目标（LOH 近因性）：毒药在命中窗口后到达，主要污染标签而非提前驱逐候选。
