# Baseline + LOH 算法 Robustness 汇总 v6（8 groups）

基于 baseline_summary_v6 数据，`best_LOH` 使用 MR=v4 + BMR(one_hit≤0.67→ns_f100, else v5) 混合策略。

**指标说明**:
- **Avg Rank**: 8 组 trace 上的平均排名（1=最优），越低越好（共 12 个算法）
- **Wins**: 在几组 trace 上排名第 1
- **Avg Norm Score**: 归一化得分平均（0=该组最优，1=该组最差），越低越好
- **Max Regret**: 与该组最优算法的最大绝对差距，越低越好
- 相对 LRU 比例表中，<1 优于 LRU，值越低越好

## 数据来源清单

- best_LOH MR: 各 group 文档 `表2` 的 v4 规则
- best_LOH BMR: `tmp/20260420-nosize-allgroups/logs/*.log` 提取 one_hit 与 ns_f100 BMR，再按 one_hit 阈值与 v5 规则分流
- 其他算法 MR/BMR: 各 group 文档表4/表5，按请求数加权来自表1
- 排名类指标: 由本文件 8 个指标在 8 组数据上重新计算
