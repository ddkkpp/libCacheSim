# Auto-Compound 判断指标分析报告

## 1. 数据集

- 有效 traces: 1115 (完整 8 configs + WARMUP_DIAG)
- 有 R2m 系列指标: 1002, 仅 r1/r2: 113 (old format, cloudphysics)
- fs 有利: 452 (40.5%), fs 无益: 663 (59.5%)
- rs 有利: 501 (44.9%), rs 无益: 614 (55.1%)

## 2. FS (freq_size) 判断：单指标 threshold sweep

| 指标 | 语义 | Best Threshold | Best avg_gap |
|------|------|---------------|-------------|
| r1 = Pearson(freq, freq/size) | 越高越关 | 0.9359 | 1.602% |
| **R2m_fs = MultiR²(fs ~ f+s)** | **越高越关** | **0.9825** | **1.323%** |
| cv_sz (size 变异系数) | 越低越关 | 0.1378 | 1.670% |
| r4 = Pearson(size, freq/size) | 越高越关 | -0.4776 | 1.378% |
| 1-R2m_fs (信息增益) | 越低越关 | 0.0175 | 1.323% |

**结论: R2m_fs (Multiple R²) 是 FS 维度最优单指标**，比 r1 好约 0.28% avg_gap。

## 3. RS (rec_size) 判断：单指标 threshold sweep

| 指标 | 语义 | Best Threshold | Best avg_gap |
|------|------|---------------|-------------|
| r2 = Pearson(rec, rec×size) | 越高越关 | 0.8700 | 3.759% |
| R2m_rs = MultiR²(rs ~ r+s) | 越高越关 | 0.9992 | 3.602% |
| **cv_sz (size 变异系数)** | **越低越关** | **0.0639** | **3.616%** |
| r5 = Pearson(size, rec×size) | 越高越关 | 0.8890 | 3.701% |
| |r_AC| = |Pearson(rec, size)| | 越高越关 | 0.3520 | 3.571% |

RS 维度各指标差异小(3.57-3.76%)，cv_sz 和 |r_AC| 略优。

## 8. R2m_fs > 0.98 子集内的困境

- 846 traces 中 R2m_fs > 0.98
  - fs 有利 (>1% 改善): 213 (25.2%) — 主要是 alibaba_1M/100K
  - fs 有害 (>1% 恶化): 408 (48.2%)
  - fs 中性: 225 (26.6%)
- 在此子集内，helpful vs harmful 的子指标差异很小：
  - R2m_fs: 0.9936 vs 0.9966 (Δ=0.003)
  - r1: 0.9658 vs 0.9879 (Δ=0.022) — 有一些区分力
  - cv_sz: 0.112 vs 0.102 (Δ=0.010) — 极小
  - avg_sz: 33426 vs 20537 — **helpful 组平均 size 更大**
  - n_obj: 83861 vs 112550 — **helpful 组对象数更少**

**这是核心瓶颈**: 即使 R2m_fs ≈ 1.0 (compound 几乎被 base 完全解释)，CMA-ES 非线性加权仍可能从 fs 中获益。这不是线性统计能捕捉的。

## 9. wiki_2019t 特例

- R2m_fs = 0.9954, r1 = 0.9915 → 所有策略都关闭 fs
- 实际 f010 (fs only) = 0.1706, f000 = 0.1753, gap = 5.78%
- 这是 CMA-ES 非线性利用 freq/size 比率的典型案例
- **不可能用单一线性指标解决**

## 10. 推荐方案: Auto-Compound v5

```
FS 决策:
  if R2m_fs 可用:  关 fs 当 R2m_fs > 0.98
  else (fallback): 关 fs 当 r1 > 0.93

RS 决策:
  关 rs 当 cv_sz < 0.04

freq_rec: 永远关闭 (bit0=0)
```

**预期效果**: avg_gap 从 3.97% → 3.05%（改善 0.92%），主要受益于 alibaba_1M 组。
