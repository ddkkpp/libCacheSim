# Auto-Compound v6 设计文档

> **日期**: 2026-04-17
> **前置**: `docs/20260412-AUTO_COMPOUND_V5_DECISION.md` (v5)
> **数据来源**: `tmp/20260416-per-feature-sweep/` (7 traces × 64 configs)

## 1. v5 的困境

v5 决策规则：
- FR = 1（固定开启）
- FS = (r1 <= 0.98) ? 1 : 0
- RS = (r2 <= 0.98) ? 1 : 0

**问题**：在 7 条 meta traces 上，r1 范围 0.77-0.97，r2 范围 0.12-0.41，全部远低于 0.98 阈值。因此 v5 对所有 trace 都预测 f111，**0/7 匹配 sweep 最优**。

| Trace | r1 | r2 | v5 预测 | MR最优 | Joint最优 |
|-------|----|----|---------|--------|-----------|
| meta_reag | 0.78 | 0.31 | f111 | f001 | f010 |
| meta_rnha | 0.81 | 0.37 | f111 | f001 | f001 |
| meta_rprn | 0.77 | 0.33 | f111 | f011 | f010 |
| meta_kvcache | 0.97 | 0.41 | f111 | f011 | f110 |
| 202206_kv | 0.97 | 0.38 | f111 | f010 | f110 |
| 202210_kv | 0.83 | 0.15 | f111 | f011 | f110 |
| 202401_kv | 0.81 | 0.12 | f111 | f010 | f100 |

## 2. 逐位分析

### 2.1 FR 位（最关键）

**ALL 7 traces 的 MR-最优 FR=0**。v5 固定 FR=1 是 MR 回归的主因。

| 类型 | FR=0 vs FR=1 MR 差距 | FR=0 vs FR=1 BMR 差距 |
|------|---------------------|-----------------------|
| CDN (3) | <0.01% (可忽略) | <1% (可忽略) |
| KV (4) | **-2.2% ~ -5.4%** (FR=0 大幅更优) | +60~80% (FR=0 BMR 大幅更差) |

**FR 是一个 MR vs BMR 的尖锐 tradeoff**：
- FR=1: BMR 大幅改善 (-2%~-40%), MR 小幅恶化 (+0.1%~+5%)
- FR=0: MR 最优, BMR 可能恶化

v5 的 FR=1 是基于 Joint=0.5×MR+0.5×BMR 优化的。如果只看 MR，FR=0 总是更好。

### 2.2 FS 位

| 类型 | 最优 FS | 诊断信号 | 敏感度 |
|------|---------|----------|--------|
| CDN | 0 或 1 (无差) | - | <0.01% |
| KV | **1** (全部) | cv_freq>=0.55 | 中等 |

r1>0.98 gate 对 cloudphysics "地雷" traces 仍有保护作用（7 个 r1≈0.99 trace 启用 FS 会 +137%~453%）。

### 2.3 RS 位

| 类型 | 最优 RS | 诊断信号 | 敏感度 |
|------|---------|----------|--------|
| CDN | **1** (全部) | - | <0.01% |
| KV | 混合 (1 or 0) | 无清晰信号 | **0.0%~0.6%** |

RS 对 KV 的敏感度很低（0-0.6%），无法在诊断阶段精确预测。安全默认 RS=1。

## 3. 可用诊断信号

**cv_freq（log域频率变异系数）** 是最佳分类器：

| 类型 | cv_freq 范围 | 间隔 |
|------|-------------|------|
| CDN | 0.47 ~ 0.48 | — |
| (gap) | — | 0.19 |
| KV | 0.67 ~ 0.70 | — |

cv_freq = 0.55 的分类阈值有 CDN 侧 0.07、KV 侧 0.12 的安全裕度。

## 4. v6 设计

### 4.1 核心变更

**FR 从"固定=1"改为"cv_freq 依赖"**：

```c
// v5: loh_use_freq_rec = 1;  // 固定
// v6:
if (cv_freq >= cv_threshold) {
    loh_use_freq_rec = 0;  // KV: FR 严重损害 MR (2-5%)
} else {
    loh_use_freq_rec = 1;  // CDN/通用: FR 有益 BMR, MR 影响<0.01%
}
```

FS/RS 规则不变（r1>0.98 gate, r2>0.98 gate）。

### 4.2 参数

| 参数 | 默认 | 环境变量 |
|------|------|----------|
| cv_freq 阈值 | 0.55 | `LOH_AUTO_COMPOUND_CV_THRESHOLD` |
| r 阈值 | 0.98 | `LOH_AUTO_COMPOUND_R_THRESHOLD` (保留) |

### 4.3 v6 预测结果

| Trace | cv_freq | v6 预测 | MR最优 | v6 MR gap |
|-------|---------|---------|--------|-----------|
| meta_reag | 0.47 | f111 | f001 | 0.00% |
| meta_rnha | 0.48 | f111 | f001 | 0.01% |
| meta_rprn | 0.48 | f111 | f011 | 0.00% |
| meta_kvcache | 0.67 | **f011** | f011 | **0.00%** ★ |
| 202206_kv | 0.69 | **f011** | f010 | **0.61%** ★ |
| 202210_kv | 0.70 | **f011** | f011 | **0.00%** ★ |
| 202401_kv | 0.70 | **f011** | f010 | **0.46%** ★ |

### 4.4 v5 vs v6 对比

| 指标 | v5 | v6 |
|------|----|----|
| MR max gap | 5.39% | **0.61%** (9× 改善) |
| MR avg gap | 1.65% | **0.15%** (11× 改善) |
| CDN 行为 | f111 | f111 (不变) |
| KV 行为 | f111 | **f011** (FR 关闭) |
| cloudphysics 安全 | r1>0.98 gate | 不变 |

### 4.5 Joint 指标影响

v6 对 KV 的 Joint 会变差（因为 FR=0 导致 BMR 恶化）：

| Trace | v5 Joint | v6 Joint | 变化 | v5 MR | v6 MR | MR 改善 |
|-------|----------|----------|------|-------|-------|---------|
| meta_kvcache | 0.0862 | 0.1015 | +17.8% ↑ | 0.0575 | **0.0546** | -5.1% ↓ |
| 202206_kv | 0.0557 | 0.0631 | +13.3% ↑ | 0.0342 | **0.0331** | -3.2% ↓ |
| 202210_kv | 0.0775 | 0.0781 | +0.9% | 0.0336 | **0.0329** | -2.3% ↓ |
| 202401_kv | 0.0499 | 0.0508 | +1.7% | 0.0496 | **0.0488** | -1.7% ↓ |

**这是 MR vs BMR 的根本 tradeoff**。v6 选择优化 MR。

## 5. 限制

1. **BMR 回退**: KV traces 的 BMR 会恶化（FR=0 失去了 freq_rec compound 对 byte-level 评分的帮助）
2. **cv_freq 未验证**: alibaba/cloudphysics 的 cv_freq 值未确认。假设它们 <0.55（存储/CDN 特征），否则 FR 会被错误关闭
3. **RS 仍无法精确预测**: KV RS 最优值（0 vs 1）在诊断阶段不可区分，但敏感度低（<0.6%）
