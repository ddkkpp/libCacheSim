# Baseline + LOH 算法 Robustness 汇总 v7（8 groups）

基于 baseline_summary_v7 数据，`best_LOH` 使用 v7 固定策略：
- MR: 固定取 `f001_orig`（fallback: `f100_ns`）
- BMR: `one_hit<=0.72` 取 `f100_ns`，`one_hit>0.72` 取 `f101_orig`（fallback: `f100_ns`）

**指标说明**:
- **Avg Rank**: 8 组 trace 上的平均排名（1=最优），越低越好（共 12 个算法）
- **Wins**: 在几组 trace 上排名第 1
- **Avg Norm Score**: 归一化得分平均（0=该组最优，1=该组最差），越低越好
- **Max Regret**: 与该组最优算法的最大绝对差距，越低越好
- 相对 LRU 比例表中，<1 优于 LRU，值越低越好

## 数据来源清单

- best_LOH MR: 各 group 文档 `表2` 固定取 `f001_orig`（缺失回退 `f100_ns`）
- best_LOH BMR: 各 group 文档 `表1(one_hit)` + `表3` 按 `0.72` 阈值在 `f100_ns/f101_orig` 间分流（缺失回退 `f100_ns`）
- 其他算法 MR/BMR: 各 group 文档表4/表5，按请求数加权来自表1
- 排名类指标: 由本文件 8 个指标在 8 组数据上重新计算
