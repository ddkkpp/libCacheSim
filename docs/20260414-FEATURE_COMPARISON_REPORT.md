# Feature Selection 对比报告 (2026-04-14)

## 实验概述

三组实验，3 trace × 8 feature 配置，共比较 **固定权重 / 无 sigma-fix CMA-ES / 带 sigma-fix CMA-ES** 的 miss ratio 表现。

**Feature 编码**：f{freq_rec}{freq_size}{rec_size}，1=开启对应交叉特征
- 基础 3 维：recency(w0) / frequency(w1) / size(w2)，始终开启
- f000 = 仅基础 3 维 (active_dim=3)
- f011 = 基础 + freq×size + rec×size (active_dim=5)
- f111 = 全部 6 维 (active_dim=6)

**Trace**：
- 1063 = tencentBlock_1063 (360M req, ~600K objects, cache 0.1)
- meta = meta_reag CDN (46M req, cache 0.1)
- wiki = wiki_2019t (207M req, cache 0.1)

---

## 1. 固定权重 (fixed-05)

CMA-ES 开启但权重被 LOH_FIXED_WEIGHTS 覆盖，不优化。每个 feature config 使用对应的权重向量（开启维=0.5，关闭维=0）。

- **1063**：f011(freq×size + rec×size) MR 和 BMR 均最佳；f100(freq×rec) 最差

- **wiki**：MR 上 f010 最优，BMR 上 f110 最优（0.1296）——BMR 维度对大对象更敏感

### 结论

1. **sigma-fix 对所有 3 个 trace 均有害或无益**：no-cs 在所有 trace 上都优于 sweep 最佳
2. **CMA-ES 无 sigma-fix 对 1063 有帮助**：no-cs f011(0.01717) 比 fixed-05 f011(0.01842) 好 6.8%
3. **CMA-ES 对 meta/wiki 几乎无帮助**：no-cs ≈ fixed-05（差异 < 0.04%）
4. **feature 选择比 CMA-ES 参数调优更重要**：
   - 1063 上 f011 vs f100 差距 = 49 个百分点的 MR
   - meta/wiki 上 feature 差异小

### FSB 自动特征选择验证

FSB 在 1063 上自动选择了 **f011**（5 轮锁定），与 no-cs / fixed-05 实验的最佳 feature 一致。
