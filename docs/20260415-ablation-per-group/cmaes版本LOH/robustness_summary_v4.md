# Baseline + LOH 算法 Robustness 汇总 v4（8 groups）

基于 baseline_summary_v4 数据，`best_LOH` 使用 MR=v4规则 + BMR=规则A（nosize whitelist）混合策略。

**指标说明**:
- **Avg Rank**: 8 组 trace 上的平均排名（1=最优），越低越好（共 12 个算法）
- **Wins**: 在几组 trace 上排名第 1
- **Avg Norm Score**: 归一化得分平均（0=该组最优，1=该组最差），越低越好
- **Max Regret**: 与该组最优算法的最大绝对差距，越低越好
- 相对 LRU 比例表中，<1 优于 LRU，值越低越好

**Avg Norm Score 计算公式**:

- 设某个指标在 group `g` 上，算法 `a` 的值为 `x(a,g)`
- 先对该 group 内所有算法做归一化：`norm(a,g) = (x(a,g) - min_g) / (max_g - min_g)`
- 若所有算法数值完全相同（`max_g = min_g`），则定义 `norm(a,g) = 0`
- 最终 `Avg Norm Score(a) = mean_g(norm(a,g))`，即对 8 个 group 的归一化分数取平均

## 数据来源清单

- best_LOH MR: 各 group 文档 `表2` v4 cfg 规则选值（FR=0, FS=(r1≤0.98), RS=(r2≤0.98)）
- best_LOH BMR: 规则A — cloudphysics/metaKV/tencentPhoto/wiki 用 nosize，其余用 f101
- 其他算法 MR/BMR: 各 group 文档表4/表5，按请求数加权来自表1
- 排名类指标: 由本文件 8 个指标在 8 组数据上重新计算
