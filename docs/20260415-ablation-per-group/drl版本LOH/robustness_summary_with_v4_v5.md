# Baseline + LOH 算法 Robustness 汇总（8 groups，DRL 版本 LOH）

DRL 目录没有与 cmaes AUTO_COMPOUND 对应的 v4/v5 额外算法；本文件保留同名输出，算法集合与 robustness_summary 相同。

**指标说明**:
- **Avg Rank**: 8 组 trace 上的平均排名（1=最优），越低越好（共 12 个算法）
- **Wins**: 在几组 trace 上排名第 1
- **Avg Norm Score**: 归一化得分平均（0=该组最优，1=该组最差），越低越好
- **Max Regret**: 与该组最优算法的最大绝对差距，越低越好
- 相对 LRU 比例表中，<1 优于 LRU，值越低越好

**Avg Norm Score 计算公式**:

- 设某个指标在 group `g` 上，算法 `a` 的值为 `x(a,g)`
- 先对该 group 内所有算法做归一化：`norm(a,g) = (x(a,g) - min_g) / (max_g - min_g)`，其中 `min_g = min_b x(b,g)`，`max_g = max_b x(b,g)`
- 若该 group 内所有算法数值完全相同（`max_g = min_g`），则定义 `norm(a,g) = 0`
- 最终 `Avg Norm Score(a) = mean_g(norm(a,g))`，即对 8 个 group 的归一化分数取平均
