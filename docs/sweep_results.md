## 重要坑 / 规则（必须遵守）

1) **共享内存布局必须与 C 编译一致**

- `LOH_INCLUDE_REQUEST=1` 等维度相关宏必须与 C 端编译宏一致，否则会出现 Python 早退、cachesim 被 watchdog 强停、指标 NA。

2) **不要显式写 `LOH_INCLUDE_CACHE_FEATURES=0` 这类“关闭”**

- 观察到在某些情况下，显式设置 `LOH_INCLUDE_CACHE_FEATURES=0` 会导致 run 直接失败（exit=1/NA）。
- 推测原因：若 C 侧使用 `#ifdef LOH_INCLUDE_CACHE_FEATURES` 风格判断，则“定义但为 0”仍会进入分支，导致 C/Python 结构体维度不一致。
- 规则：**关闭某宏时，直接不设置该环境变量**；开启时才设置为 `1`。
