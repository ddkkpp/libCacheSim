### 分析

- **metaCDN (reag/rnha/rprn)**: Identity 归一化全面优于 Log1p，且几乎追平 GDSF（gap ≤ 0.03%）。
- **metaKV 和所有 kv_traces**: Identity 严重退化（+22%~+41%），完全不可接受。
- **根因推测**: metaCDN 的特征值域分布较均匀，Identity 直传无损信息;  metaKV 特征值域跨度大（访问频率从 1 到 10⁶），不做 log1p 压缩会导致 CMA-ES 优化景观严重倾斜。

## 7. 关键结论

1. **关闭 degrade_detect (G1 vs OLD)**: 稳定改善约 0.8%，是当前最安全的改进。
2. **Identity 归一化 (G2)**: 对 metaCDN 负载效果极好（接近平 GDSF），但对 metaKV/kv_traces 负载严重退化，不可全局采用。
3. **大 RL_UPDATE_INTERVAL (G3=5000, G4=100)**: 两种非默认间隔均全面退化，且 G3 与 G4 效果几乎相同。不推荐修改此参数。
4. **最佳策略**:
   - metaCDN 类负载（值域均匀）→ 使用 Identity 归一化 (G2 配置)
   - metaKV / kv_traces 类负载（值域跨度大）→ 使用 Log1p + degrade_detect=0 (G1 配置)
   - 如需统一配置 → G1 (Log1p, degrade_detect=0) 是最安全的选择

### 10.5 维度影响分析

| 维度 | metaCDN 最优 | metaKV/kv 最优 | 分歧原因 |
|------|-------------|---------------|---------|
| REC | identity (−0.05%~−0.90%) | log1p (+0.60%~+3.86%) | CDN recency 分布较均匀; KV 长尾 |
| FREQ | 几乎无差 (~0%) | log1p (+4.5%~+9.8%) | KV freq 跨度 1~10⁶ 需要压缩 |
| SIZE | identity (−0.10%~−1.25%) | log1p (+3.0%~+10.1%) | CDN 对象大小较一致; KV 大小差异巨大 |

**关键发现**:
1. **FREQ log1p 对 KV 负载影响最大**（+4.5%~+9.8% 退化 if 用 identity），是最关键的维度。
2. **metaCDN 全维度偏好 identity** — 与 G2 (全局 identity) 结论一致，但 PF 通过精细组合达到了相同效果且无副作用。
3. **metaKV 全维度偏好 log1p** — 与 G1 (全局 log1p) 结论一致，但 PF 通过 compound+perfeat 联合优化超越了 G1。
4. **最佳 perfeat 模式因 trace 而异**，不存在全局最优的单一 pf 配置。
