# w0.7 vs w1.0 Feature Ablation 对比分析

**日期**: 2026-04-15
**实验来源**:
- w1.0 数据: `docs/20260415-ablation-per-group/` (历史 ablation 实验)
- w0.7 数据: `tmp/20260415-feature-sweep-w07/` (新跑实验, 24 个全部完成)

**实验配置**:
- 共同参数: `LOH_FSB=0, LOH_AUTO_COMPOUND=0, LOH_SCORE_USE_COMPOUND=1, LOH_FEATURE_LOG1P=1, LOH_ENABLE_CMAES=1, LOH_ENABLE_RL=0, SC=16`
- w1.0: `LOH_MISS_RATIO_WEIGHT=1.0` (纯 MR 优化)
- w0.7: `LOH_MISS_RATIO_WEIGHT=0.7` (0.7×MR + 0.3×BMR 混合优化)

**特征配置编码**: `fXYZ` = `freq_rec=X, freq_size=Y, rec_size=Z`

## 总结

| 维度 | 1063 | wiki_2019t | meta_reag |
|---|---|---|---|
| w0.7 vs w1.0 最优 MR | w0.7 微优 1.3% | 无差异 | 不可比 |
| 最优 config 是否迁移 | 是 (f001→f011) | 否 (f010) | 是 (f011→f101) |
| w0.7 优/劣配置数 | 3 优 5 劣 | 全平 | 全优(混杂) |
| 可信度 | ✅ 高 | ✅ 高 | ⚠️ 低 |

**结论**: **建议继续使用 w1.0**
1. wiki 完全不敏感 — 无区别
2. 1063 上 w0.7 最优微优 1.3%，但让 5/8 配置变差，鲁棒性下降
3. meta_reag 对比因 RC 不同而不可信
4. w1.0 = 纯 MR 优化，物理含义清晰，调参更简洁
