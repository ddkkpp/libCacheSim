## 数据来源清单

- BMR加权类（BMR 按请求数加权平均值 / BMR 按请求数加权标准差）: `表1(n_req)` + `表5(BMR)`

- BMR相对LRU类（BMR 相对LRU比例及其标准差）: `表5` 内同 trace 的 `algo/LRU` 比值
