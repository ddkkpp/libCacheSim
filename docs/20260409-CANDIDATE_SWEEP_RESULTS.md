## 关键结论

1. **MR 单指标最优：r96\_s96**（normMR=0.0050，4 trace 平均 avg MR #1），
   但其 BMR 归一化得分偏高（normBMR=0.5313，相当于 BMR 中游），综合排 **#7**。

2. **MR+BMR 综合最优：r256\_s64**（综合分=0.2240，normMR=0.1052，normBMR=0.3428，MQPS=0.65）；
   **r128\_s16** 综合 #2（综合分=0.2252），BMR 归一化最优（normBMR=0.2168）。

3. **当前代码默认值 r256\_s16** 综合排 #4（comb=0.2537），MR 和 BMR 均衡；
   若优化目标是纯 MR，换用 r96\_s96 可降低 MR；若综合考虑，r256\_s64 更优。

4. **Random 候选数是主导因素**（对 1063 影响尤为显著）：
   - RAND=16: MR ≈ 0.04–0.19（极差，CMA-ES 探索空间不足）
   - RAND=64: MR ≈ 0.086（明显跳跃）
   - RAND=96: MR ≈ 0.025–0.050（MR 最佳平衡点，但 BMR 偏高）
   - RAND=192/256: MR ≈ 0.022–0.032，BMR 也相对更优（大搜索空间兼顾两者）

5. **Structured 候选数影响较小**，但不同指标偏好不同：
   - 优化 MR：struct≈rand 等比效果好（对角线效应）
   - 优化 BMR：较小 struct（s16/s32）更优（r128\_s16、r256\_s32 分列 BMR #1/#2）

6. **本实验使用固定 compound=f111**（未开启 `LOH_AUTO_COMPOUND`），
   结论适用于 f111 模式下的候选数量选择。

### AC=1 优势机制分析

1. **warmup 阶段用 3 维（compound=0）**：CMA-ES 在低维空间快速收敛到合理的基础权重
2. **诊断去除冗余维度**：去掉 freq/rec（R²=0.957，信息与基础维高度重叠），减少搜索空间噪声
3. **5 维正式运行**：比 6 维少一个自由度，CMA-ES 更难陷入高 sigma 发散
4. **低候选数配置获益最大**：AC=0 下 r16/r32 系列 MR 极差（0.15-0.19），因为候选不足且 6 维搜索空间过大；AC=1 减维后即使少量候选也能有效优化

### 结论与建议

- **强烈建议将 `LOH_AUTO_COMPOUND=1` 设为默认值**
- AC=1 同时改善了 MR（−71%）、稳定性（CV −80%）和吞吐（+18%）
- 对配置选择的敏感性大幅下降：AC=1 下即使 r16\_s128 也能达到 MR=0.0196，接近 AC=0 的全局最优
- AC=1 + r192\_s64 为 1063 trace 最优配置，MR=0.01609
