# Reward / State 不敏感的机制分析

本文整理的是对当前 LOH + RL 实验现象的机制解释，用来回答一个核心问题：为什么在固定 reward 或固定 state 后，最终 miss ratio 变化很小，而吞吐会有轻微波动。

请你以“缓存替换算法 + 强化学习信用分配”专家身份，评估一个方法论问题：为什么在我的系统里，改变 reward 定义或把 state 固定为常数，最终 miss 指标几乎不变？

一、算法设置（抽象描述）

任务：在线缓存替换，目标最小化 miss ratio（以及可选 byte miss ratio）。

基础策略：C 端会对候选对象计算分数，按分数执行驱逐。

RL 角色：Python 侧输出权重，权重作用于候选特征加权打分。

观测：以全局命中相关统计 + 候选统计特征构成。

动作：权重向量（用于线性或复合评分）。

奖励：可由命中率、趋势项、惩罚项等组合；也可固定成常数。

训练范式：在线、异步、延迟信用分配（部分奖励在后续时刻回填）。

二、对照实验（核心事实）

在相同 trace 与 cache size 下，做了以下变体：

原始 reward/state。

固定 reward 常数。

固定 state 常数。

同时固定 reward + state。

结果：最终 miss ratio 几乎重合，仅有极小扰动。

提示：

真实决策主要由非 RL 打分主干决定。

环境中“可控自由度”远小于“启发式强约束”。

对“缓存替换 + 延迟回报”场景，如何判断是信用分配失败而不是探索失败？

轨迹内动作多样性。

必须能区分以下四种原因：

奖励无信息。

五、补充背景（可用于推理）

当前系统中，C 端候选分数存在明显启发式结构。

RL 权重只是其中一个可调入口。

观测与奖励都可能存在非平稳与延迟。

实验数据显示：固定 reward/state 后 miss 基本不变

## 最可能机制排名（1 到 5）

1. 动作对真实驱逐排序的边际影响太小（最可能）
2. 启发式主干过强，RL 只在极小残差区间微调
3. 奖励在训练样本上近似常数或信噪比过低，梯度有效信息接近 0
4. 延迟回报下的信用分配失败（有探索但学不到“哪步导致收益”）
5. 策略已退化为近固定策略，state 退化为常数后几乎不再损失

你当前现象“固定 reward / 固定 state 后 miss 基本不变，但吞吐有小波动”，最符合 1 + 2 + 4 的叠加：miss 由 C 端强启发式结构主导，RL 入口对排序影响不足；学习信号主要改变了系统开销路径（同步、训练、日志、IPC 负载），所以吞吐会抖动而 miss 不怎么动。

## 每个机制的数学直觉（含简化公式）

### 1. 动作影响太小：排序不变则 miss 不变

设候选分数

$$
S_i = H_i + \lambda \cdot f_\theta(x_i, a_t)
$$

其中 $H_i$ 是启发式主干，$\lambda$ 是 RL 通道增益。若

$$
\mathrm{Var}(H_i) \gg \mathrm{Var}(\lambda f_\theta)
$$

则候选排序几乎由 $H_i$ 决定，$a_t$ 改变也不改 argmax / argmin，最终 miss 基本重合。

### 2. 启发式已接近主导最优：RL 只能调残差

可写成

$$
J(\pi) = J(H) + \Delta J_{RL}
$$

若 $|\Delta J_{RL}|$ 远小于测量噪声与轨迹波动，则你看到的就是“各种 reward / state 改法都差不多”。

### 3. 奖励无信息或低信噪比：策略梯度方向塌陷

策略梯度

$$
g = \mathbb{E}\left[\sum_t A_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\right]
$$

若 $r_t \approx c$（常数）或优势函数 $A_t$ 近零均值高方差噪声，则 $g$ 的有效方向消失，训练近似随机游走或只受正则项影响。

### 4. 延迟信用分配失败：不是“没探索”，而是“探索结果对不上账”

长期奖励

$$
R_t = \sum_{k \ge 0} \gamma^k r_{t+k}
$$

若关键行为与可见奖励间隔远大于有效 credit horizon，或者回填链路噪声大，$Q(s_t, a_t)$ 可分性弱，学习不到因果映射。

### 5. state 变常数后不掉点：策略本来就近常量策略

若

$$
\pi_\theta(a \mid s) \approx \pi_\theta(a)
$$

则把 $s$ 固定为常数几乎不改变动作分布，自然 miss 不变。

## 如何区分“信用分配失败”与“探索失败”（可观测判据）

### 1. 轨迹内动作多样性

看动作熵 $H(a_t \mid s_t)$、覆盖率、有效样本数。

- 低熵低覆盖：偏探索失败。
- 熵不低但性能不学：偏信用分配失败。

### 2. 同状态不同动作的价值可分性

估计 $\Delta Q(s, a_1, a_2)$ 或离线反事实价值差。

- 若长期接近 0：可能动作本身不影响决策，或启发式压制。
- 若存在可分性但策略学不到：偏信用分配失败。

### 3. 奖励对动作扰动灵敏度

在相同状态做小扰动 $a \to a + \epsilon$，看

$$
\frac{\partial \mathbb{E}[r]}{\partial a}
$$

或有限差分。若接近 0，reward 对 action 不敏感。

### 4. 迟到奖励与前序动作的信息量

计算 $I(a_t; r_{t+\tau} \mid s_t)$ 或相关函数随 $\tau$ 的衰减。

- 全程接近 0：奖励链路几乎无可学习信号。
- 在某些滞后有峰值但训练仍无效：大概率 credit 机制设计不匹配。

## 最小化消融矩阵（区分 4 类根因）

目标区分：

- A 奖励无信息
- B 状态无信息
- C 动作未真正影响决策
- D 启发式主干过强，RL 边际极小

建议 6 组最小矩阵（同 trace、同 cache size，多随机种子）：

1. Full：真实 state + 真实 reward + 动作接入正常 + 原启发式
2. Const-R：state 真，reward 常数
3. Const-S：state 常数，reward 真
4. Const-RS：state 常数 + reward 常数
5. No-Act：策略仍输出，但动作通道在 C 端断开或置零增益，$\lambda = 0$
6. Weak-H / Amplify-Act：削弱启发式温度或放大动作增益（提高 $\lambda$）

### 判读规则

- 若 1≈2≈3≈4≈5，且 6 才出现明显变化：结论偏 D（主干过强）+ C（动作入口太弱）
- 若 1 明显优于 2/4，但 1≈3：结论偏 A（reward 有信息，state 可能冗余）
- 若 1 明显优于 3/4，但 1≈2：结论偏 B（state 有信息，reward 配方可能冗余或被 baseline 吸收）
- 若 1≈5：结论偏 C（动作未真正影响决策）
- 若动作多样性高但 1 与 2/4 仍近似，且互信息低：结论偏 A + 信用分配失败（非探索失败）

## 可执行算法验证路线图（按优先级）

### 1. 先做“因果入口”验证（最高优先级）

用 No-Act 与 Amplify-Act 两组，先证明动作是否真能改变候选排序与最终 miss。

如果这一步不过，后续 reward / state 讨论都不成立。

### 2. 再做“信息性”验证

跑 Full / Const-R / Const-S / Const-RS，配合动作熵、$\Delta Q$ 可分性、奖励灵敏度，判定 reward 与 state 的真实信息贡献。

### 3. 做“信用链路”验证

固定探索强度（保证动作分布不塌），只改变 credit horizon、回填窗口、优势估计方式；观察 $I(a_t; r_{t+\tau} \mid s_t)$ 与性能是否同步改善。

若互信息有峰但性能不涨，通常是 credit 机制与延迟结构不匹配。

### 4. 做“主干-学习器权力重分配”

系统性扫描启发式强度与动作增益比值，寻找 RL 产生可见边际收益的工作区间，而不是只在当前强约束点下比较。

### 5. 最后才调 reward 配方细节

在确认动作有效、state 有信息、credit 可传递后，再调趋势项 / 惩罚项权重，否则容易出现“怎么改 reward 都没差”的假象。

## 一句话结论

你这个现象在理论上完全常见，最可能不是“RL 学得太差”单点问题，而是“动作影响链路太弱 + 启发式主导 + 延迟信用信号不足”的组合，使 reward / state 改动在 miss 指标上被系统结构性吞没。吞吐小波动则是训练与系统开销路径变化的外在表现。
